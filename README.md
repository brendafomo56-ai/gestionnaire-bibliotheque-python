# 📚 Gestionnaire de Bibliothèque en Python

Un projet simple, interactif et robuste développé en Python pour apprendre à manipuler les **listes**, les **dictionnaires**, les boucles et la gestion des erreurs.

## 🚀 Fonctionnalités

Le programme propose un menu interactif avec les options suivantes :
1. **Afficher tous les livres** de la bibliothèque avec leur statut (lu / non lu).
2. **Ajouter un nouveau livre** (titre et auteur).
3. **Rechercher un livre** par son titre.
4. **Modifier le statut d'un livre** (le faire passer de "non lu" à "lu").
5. **Supprimer un livre** de la bibliothèque.
6. **Quitter** le programme proprement.

## 🛠️ Notions techniques utilisées
* Variables et types de données
* Structures de données combinées : **Listes** (`[]`) et **Dictionnaires** (`{}`)
* Boucles (`while`, `for`) et conditions (`if`, `elif`, `else`)
* Gestion des erreurs avec `try / except` pour éviter les plantages en cas de saisie invalide.
* Fonctions de chaînes de caractères (`.lower()`, `.strip()`)
